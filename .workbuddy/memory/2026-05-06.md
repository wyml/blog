## 2026-05-08

### 修复 RSS 链接域名问题

**问题：** 生成的 RSS（`public/index.xml`）中所有链接指向 `http://localhost:60074/` 而非正式域名 `https://landonblue.cn/`。

**根因：** 本地 `hugo server` 会临时替换 `baseURL`，若未用正确命令重新构建，旧的 `public/` 文件会保留 localhost 链接。Vercel 没有 `vercel.json`，可能不会显式传入 `--baseURL`。

**解决方案：**
1. 新建 `D:/CODE/blog/vercel.json`，明确指定构建命令：
   ```json
   { "buildCommand": "hugo --minify --baseURL https://landonblue.cn/", "outputDirectory": "public", "framework": "hugo" }
   ```
2. 本地重新构建验证：`hugo --minify --baseURL "https://landonblue.cn/"`
3. 结果：`public/index.xml` 中 localhost 出现次数 0，landonblue.cn 出现 13 次，正确。
4. 已 push 到 GitHub，Vercel 会自动重新部署。
